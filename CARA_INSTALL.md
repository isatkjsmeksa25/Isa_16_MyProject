# Cara Menjalankan MenuKu di Laptop Windows

## Sebelum Menjalankan

Pastikan kamu menggunakan laptop atau PC dengan sistem operasi **Windows**.

## Cara Instal / Menjalankan

1. Unduh atau salin file `main.exe`.
2. Simpan di folder mana pun, misalnya `Dokumen\MenuKu`.
3. Klik dua kali `main.exe`.
4. Jika muncul peringatan "Windows protected your PC", klik **More info**, lalu **Run anyway**.
5. Aplikasi MenuKu akan terbuka.

Tidak perlu menginstal Python.

## Cara Memasak dengan MenuKu

1. Ketik bahan yang kamu punya, misalnya `nasi, telur, bawang putih`.
2. Klik **Tambah**.
3. Klik **Cari Resep** untuk melihat rekomendasi.
4. Klik **Lihat Detail Masakan** untuk melihat langkah memasak.
5. Klik **Tutup** untuk menutup detail.
6. Klik **Menu Acak** untuk memilih rekomendasi secara acak.

## Menambah atau Menghapus Bahan

- Untuk menambah bahan, ketik di kotak input lalu klik **Tambah**.
- Untuk menghapus bahan, klik tombol **Hapus** di samping bahan tersebut.

## Catatan

- Aplikasi ini hanya untuk Windows saat ini.
- Versi Android membutuhkan proses build khusus dengan Buildozer.
- Versi iPhone membutuhkan macOS dan Xcode.
